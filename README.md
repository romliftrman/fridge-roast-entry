One line, 127 characters, roasting a smart fridge: its overnight firmware update and its ice maker, which now holds every cube hostage until its owner accepts the new terms and conditions. Written for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, a single line, not only white space) and writes it to `/output/entry.txt`.
